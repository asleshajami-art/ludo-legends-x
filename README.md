# 🎮 LUDO LEGENDS X

### Roll. Race. Rule the Board. 👑

LUDO LEGENDS X is a modern and interactive Ludo gaming web application designed to bring a fresh and exciting experience to the classic board game.

With an attractive user interface, vibrant colours, and engaging gameplay options, this project aims to make playing Ludo more enjoyable, accessible, and user-friendly.

## ✨ Features

- 🎨 **Modern UI:** An attractive gaming interface with vibrant colours, gradients, and smooth visual effects.
- 🎲 **Interactive Gameplay:** Enjoy the classic Ludo experience with dice rolling and token movement.
- 🤖 **Play with Computer:** Challenge computer-controlled opponents if this mode is implemented and working.
- 👥 **Local Multiplayer:** Play with multiple players on the same device if supported by the current version.
- 📖 **How to Play:** Learn the game rules and understand how to play.
- 👤 **Player Profile:** Explore player information and statistics where supported.
- ⚙️ **Settings:** Access available game settings and preferences.
- 🔊 **Sound Controls:** Turn game sounds on or off.
- 📱 **Responsive Design:** Designed to provide a convenient experience across different screen sizes.

## 🎯 Project Objective

The main objective of LUDO LEGENDS X is to develop a visually appealing and user-friendly gaming application that combines the fun of traditional Ludo with a modern web interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🎮 How to Play

1. Open the game using the live website link.
2. Select an available game mode.
3. Roll the dice to play your turn.
4. Move your tokens according to the game rules.
5. Follow the turn order and try to reach the finish.
6. Complete the game and aim to win!

*Gameplay options may vary depending on the implemented version.*
